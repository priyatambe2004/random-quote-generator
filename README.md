# Veda Internship – Task 8:Random Quote Generator
 
A simple and interactive Random Quote Generator built using HTML5, CSS3, and JavaScript.

## 📌 About

This project displays a random quote along with its author whenever the user clicks the **New Quote** button.

It was created as part of **VEDA Technology Web Development Track – Task 8**.

## ✨ Features

- Displays random quotes and authors
- Contains 10+ quotes stored in JavaScript
- Generates a new quote on button click
- Prevents the same quote from appearing consecutively
- Clean and responsive user interface
- Optional quote sharing functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 Concepts Practiced

- JavaScript Arrays
- Objects
- `Math.random()`
- Event Handling
- DOM Manipulation
- Conditional Logic
